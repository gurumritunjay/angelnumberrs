# Image Upload Guide

## Images Needed from Your Original Website

Please download these images from https://www.angelnumberrs.com/ and place them in the specified folders:

### 1. Profile Image
**Download from:** Your About page (Sudha's profile photo)
**Save to:** `public/images/profile/sudha-profile.jpg`
**Description:** Your professional headshot/profile picture

### 2. Hero Background (Optional)
**Download from:** Homepage hero section
**Save to:** `public/images/hero/numbered-stones.jpg`
**Description:** The numbered stones image shown on your homepage

### 3. How to Download:
1. Visit https://www.angelnumberrs.com/
2. Right-click on images → "Save Image As..."
3. Save with the exact filenames listed above
4. Place in the corresponding folders

## Quick Command (if files are in Downloads):
```bash
# Assuming you downloaded the images
mv ~/Downloads/sudha-profile* public/images/profile/sudha-profile.jpg
mv ~/Downloads/numbered-stones* public/images/hero/numbered-stones.jpg
```

## After Adding Images:
The website will automatically display them! Refresh your browser to see the changes.
